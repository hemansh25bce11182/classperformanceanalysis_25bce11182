Manually managing student performance is time-consuming and error-prone. This program automates storing data, generating class statistics, identifying toppers and low scorers, and comparing individual performance with class averages.

This project can be used by teachers or institutions to efficiently manage and analyze student performance. It provides quick insights into class averages, toppers, low scorers, pass/fail rates, and individual comparisons. The system can be expanded to include more parameters, generate reports for multiple subjects, or integrate with databases for larger-scale use.

Target Users

1.Teachers – To track and analyze student performance efficiently.

2.School/College Administrators – To monitor class performance and generate reports.

3.Students – To compare their performance with class averages and identify areas of improvement.

High-Level Features

1.Student Management: Add and store student details (Name, Marks, Attendance, Internal Marks).

2.Class Analytics: Calculate averages, pass percentage, toppers, lowest scorers, and fail counts.

3.Individual Comparison: Compare a student’s performance against class averages.

4.Interactive Menu: Easy-to-use, menu-driven interface for smooth navigation.

5.Error Handling: Handles invalid inputs for marks, attendance, and internal scores.
